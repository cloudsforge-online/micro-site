# CloudsForge — the marketing site.
#
# Everything here is public and intended to be indexed. There is nothing behind a session on this
# surface, so there is nothing to disallow.
#
# There is deliberately NO `Sitemap:` line. A sitemap must carry absolute URLs, which means naming
# a hostname, and no artefact built in this repository is allowed to name one — the same image is
# served from localhost, from a preview deployment and from the apex, and a sitemap baked with the
# wrong host is worse than none. It belongs to whatever terminates TLS for the apex, which is the
# one component that knows what the apex is.

User-agent: *
Allow: /

# An unknown address on this site answers a real 404 rather than the 200 a single-page application
# usually returns, so a crawler that follows a stale link is told the truth and can drop it.
